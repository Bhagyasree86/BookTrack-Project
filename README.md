# BookTrack-Project

## Library Management System Using DevOps CI/CD Automation

### Project Description
BookTrack is a library management system designed to manage books, students, issuing books, and returning books. The project demonstrates DevOps practices using GitHub and Jenkins.

### Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Java, Spring Boot
- Database: MySQL
- Build Tool: Maven
- Testing: JUnit
- Version Control: Git and GitHub
- CI/CD: Jenkins
- Containerization: Docker

### Team Members and Responsibilities
1. Member 1: Frontend Development
2. Member 2: Backend Development
3. Member 3: Database Management
4. Member 4: GitHub and Jenkins CI/CD
5. Member 5: Docker, Integration Testing, and Documentation

### Main Features
- Add, view, update, and delete books
- Search for books
- Register students
- Issue and return books
- Track book availability
- Automate backend builds and tests using Jenkins
